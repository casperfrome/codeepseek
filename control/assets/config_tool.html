Provider 设置（当前模型）

直接保存到 config.yml；切换到该模型前请先填好对应 Provider 的 Key。
各协议在本项目（Codex → codeepseek → DeepSeek）的优缺点
anthropic（推荐 / 默认） — 端点 https://api.deepseek.com/anthropic。DeepSeek 官方为 agentic 编码推荐；完整工具调用；支持 cache_control 显式 Prompt 缓存断点；配合 deepseek_v4 扩展把 reasoning effort（high/xhigh→max）映射为深度思考。本仓库已实测可用。
openai-chat（备选） — 端点 https://api.deepseek.com（/v1/chat/completions OpenAI 兼容）。生态最通用，可作 anthropic 端点异常时的回退；但 reasoning 透传 / 档位控制较弱，缓存为 DeepSeek 自动上下文缓存、无法用断点精细控制，保真度略低。
openai-response（已移除） — OpenAI Responses API；DeepSeek 不提供该端点，仅 OpenAI 自身适用，故本面板不再列出。
